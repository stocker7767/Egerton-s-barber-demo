# Egertons Barber Shop

[Open the portfolio demo](https://montychaudhary.com/?monty_demo=egertons)

The **Services** page shows available cuts and prices, and the **Gallery** gives visitors a place to browse example styles before getting in touch.

## Try it

Open the mobile menu and go to **Services**, **Gallery** or **Contact**. On **Contact**, enter sample details to see the confirmation message.

This is an independent portfolio concept. To preview it locally, download the repo and open `index.html`.
